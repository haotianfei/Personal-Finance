# 部分录入期按沿用值计入并标记覆盖度（趋势汇总对齐 as-of 语义）

**状态**：已接受（2026-10-21）。规格：`.scratch/partial-entry-trend/spec.md`（§0 / §2 / §6）。

**背景**：资产快照是按日追加的，但用户很少在同一天把所有账户都录完——最新一期常常只有部分账户有记录。此前趋势聚合只汇总「期内存在记录」的资产项，未录入的资产项被直接丢弃、按 0 计入，导致最新一期净值断崖式下跌，并连带污染最高/最低值、环比与总结卡。而 `CONTEXT.md` 的「快照日期」「净资产」早已声明 as-of 语义（每个资产项取该日期（含）之前的最新一条记录），现状代码与该口径不一致。本 ADR 记录修复该偏差时确立的口径决策，并**明确这是实现对齐，不是口径变更**。

**决策**：

- **① 未录入账户沿用上次值 + 部分录入标记**：每期取「代表日」（期内最大数据日期）作为快照日期，期总额＝各资产项截至代表日最近一条有效记录金额之和；期内未更新的资产项沿用旧值，资产/负债仍按 `side` 拆分。覆盖度未满的期标记为**部分录入**。资产项三态：期内有记录（新鲜）/ 历史有记录（沿用）/ 从未录入（首录前不贡献，也不置零）。
- **② 极值/环比照常计入，并标注「含沿用值」**：最高/最低值、环比变化额、概览总结卡不排除部分录入期——沿用值是最佳估计，剔除反而制造断点与信息损失。凡统计点含有沿用值，即带「含沿用值」注记（极值卡、环比柱 tooltip、趋势图点标记）。
- **③ 覆盖度锚定代表日**：应录入账户＝提醒启用、且创建时间不晚于代表日；已更新账户＝其中截至代表日最近一条有效记录日期恰为代表日。最新期的代表日就是全局最新数据日期。覆盖度是**历史数据密度的描述性指标**，不驱动任何提醒或催办（其原先的补数对象「概览未录入提示」已于 ADR-0018 废止）。唯一例外：创建时间晚于参考日的账户不计入覆盖度分母；后建账户不进入历史期分母，避免新建账户把历史期误标为部分录入；未挂接账户的资产项仍计入金额，但不入覆盖统计。
- **④ 对齐既有词典语义**：`CONTEXT.md` 已声明的 as-of 口径即「沿用值」，本次仅让实现与之相符，并在词典补「沿用值」「覆盖度」「部分录入」三个词条；历史曲线数值随之整体变化属预期，不构成口径变更。

**Considered Options**：

- 维持现状（期内无记录即按 0 计入）→ 弃：正是断崖与极值污染的根源，且违背词典已声明的 as-of 语义。
- 缺记录按上一期数值补零/插值 → 弃：补零等同谎报归零，插值则臆造未发生的变动；沿用「最近已知值」是唯一不引入虚假信息的选择。
- 部分录入期整期剔除出图与统计 → 弃：最新期常是部分录入，剔除等于让用户看不到当前净值；且会制造新的断点，也让极值只反映「录得全」的期而非真实水平。
- 在库里存期级完整性状态 → 弃：覆盖度可由账户提醒配置与有效记录日期纯派生，存储反而制造第二真源与回填负担；本期不引入期表/迁移。
- 只在最新期沿用、历史期不改 → 弃：同一张图两套口径会让环比在分界处失真；历史各期同口径重算，接受整条曲线数值变化。

**Consequences**：

- 历史趋势数值整体变化（预期）：未录入资产项此前被误丢弃，重算后各期抬升且连续；完整录入期的数值与旧口径一致。
- 无 schema/迁移与写入路径变更：覆盖度与部分录入标记均为读端派生，回滚＝`git revert`。
- 性能：每期多一次覆盖度查询（约 +N 次/图，本机规模可接受，必要时批量化）。
