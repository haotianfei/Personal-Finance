# v4.0.0 — AI 辅助世代

**发布日期**：2026-09-19

## ⚠️ 数据库世代

- 本版本属于 **V4 数据世代**：支持 **v2.11.0+** 数据库启动时自动迁移（幂等）。
- **v1.x 不兼容**：旧记录式模型不存在自动升级路径，请先导出 CSV 重建；切勿用本版本直接打开 v1 数据库。
- 仅支持升级，不支持降级。升级前请先备份（`./backup-and-restore.sh`）。
- 详见 [docs/MIGRATION.md](../MIGRATION.md)。

## 新增

- **LLM 供应商配置**：预置 DeepSeek、阿里云百炼（DashScope）、百炼 Token Plan；Key 脱敏展示、不进入导出 bundle。
- **截图 AI 一致性校验**：视觉大模型独立识图，与 OCR 结果逐行比对（一致 / 分歧 / 单边缺项）；手动 + 自动触发；SHA256 缓存；失败静默降级、不影响主流程。
- **补录通道**：对账缺失行可手动补录，按名字键 / 内容键落库，含审计记录。
- **识别引擎双路对等**：`engine=ocr|ai`，凭证记录识别引擎。
- **账户录入提醒**：按账户配置提醒开关 + 首页横幅。
- **来源分组管理**：设置页 CRUD 与分组规则服务。

## 改进

- 异步预览任务（preview jobs）。
- OCR 多分块 + 重叠窗口 + 透视校正。
- 结构化日志（x-request-id）。

## 测试

- 后端 350 用例全绿：llm_verification、peer_engine_modes、account_reminder、preview_jobs、parser_amount_binding、rules_write_paths、screenshot_date_contract、guide_image_upload、copy_from_last 等。
- 前端 `tsc --noEmit` 0 错误；`next build` 通过（19 条路由）。

## 升级指引

1. 备份数据库（`./backup-and-restore.sh`）；
2. 更新到 v4.0.0 并重启后端，自动迁移即完成；
3. 在「设置 → LLM 供应商」填入 API Key 并启用后，即可在截图录入中使用 AI 一致性校验。
