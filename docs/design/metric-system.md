## 0. 第一原则：台账边界（非流水）【用户始终要求】

系统是**资产台账**：定期记录资产状况与变动，不是流水账。

**指标输入只允许三类**：

1. **快照序列**——资产记录（as-of 沿用口径、金额非负＋side，ADR-0015）；
2. **人裁决的变动登记**——更正（追加）、本金口径变更、转移事件、清零归档；
3. **参考区设定**——目标版本、配置框架、阈值。

**需要交易流水才能计算的指标一律不做**（明确非目标，而非暂缓）：储蓄率、结余率、消费分析、财务自由度、负债收入比、应急准备金月数等。

与既有冻结一致：R-6（不做流水级记账）、业务架构拍板 1（不重建历史流水）、业务架构拍板 9（转移事件不做流水明细）、R-8（TWR/XIRR 以「标记过的外部现金流」＝本金口径为输入）、支出模块只读遗留不纳入规划。

## 2. 分层

**L0 北极星**：**目标达成度**＝当期净值 ÷ 目标金额（对当期目标版本）；派生：缺口、所需年化、剩余期数。依据：R-28「复盘以目标达成度为锚」、不变量 6「目标由人设定」。过渡期（三期上线前）主视图＝净资产水位。

**L0′ 常驻底座指标**（「这个数字可不可信」本身也要判灯）：覆盖度、部分录入、最大沿用天数、归属未标注率、未对账差异。（2026-11-04 修订：覆盖度已退役见 ADR-0018 / ADR-0020 D2；「部分录入」已改为沿用项数／最大沿用天数 `carried_items`／`carried_max_days`，不再做完整/缺失判断。）

**L1 业务域**：不新造概念，直接用已冻结子域：B1 水位 / B2 收益 / B3 结构 / B4 信号 / C1 目标 / C2 配置 / C4 复盘（D 待四期，成员切片按 §5 预留）。

**L2 指标族 / L3 口径层级**：L3＝原子（事实聚合）→ 派生（公式）→ 复合（跨指标状态，如域级灯）；对应系统架构「比率/收益率为派生计算值，不落权威存储」。

**指标清单**（「现状」＝已上线能力；「三期」＝随 C1/C2/B4/C4 落地）：

| 指标 | 挂点 | 口径层级 | 公式/来源要点 | 现状 | 方向·用途 |
|---|---|---|---|---|---|
| 净资产/总资产/总负债 | B1 | 原子 | Σ 最新有效快照（as-of 沿用） | ✅ | 展示（辅锚） |
| 净资产趋势/环比 | B1 | 派生·序列 | 账期分组（R-14） | ✅ | 展示/诊断 |
| 覆盖度/部分录入/最大沿用天数（2026-11-04 修订：覆盖度已退役见 ADR-0018 / ADR-0020 D2；「部分录入」已改为沿用项数／最大沿用天数 `carried_items`／`carried_max_days`） | 底座 | 派生 | updated/expected | ◐ 批次待收口 | 底座信号 |
| 累计投入本金 | B2 | 原子（人裁决） | 本金变更史权威（R-6/R-9） | ✅ | 收益输入 |

| 流动性分层占比 | B3 | 派生 | 按流动性评级 | ✅ | 适宜带（判据待定） |
| 负债占比、单标的集中度 | B3 | 派生 | 负债/总资产；单标的占比 | ✅ 未判灯 | 底线（越低越好） |
| 配置偏离 | C2 | 派生 | 实际权重 − 当期目标权重（R-20/R-21） | ◐ 单阈值（V4） | 双阈值（三期） |

## 3. 分类（受控标签）

| 标签维度 | 取值 | 用途 |
|---|---|---|
| 主挂点（子域） | 如 B2 / C1（唯一） | 目录、责任归属 |
| 口径层级 | 原子 / 派生 / 复合 | 建模与血缘 |
| 形态 | 金额 / 比率 / 倍数 / 时长 / 计数 / 序列 / 状态灯 | 计算与渲染 |
| 时间语义 | 时点(as-of) / 期间(账期) / 跨期(环比·趋势) | 净值是时点、收益是期间，不可混 |
| 方向性 | 越高越好 / 越低越好 / 适宜带 / 双阈值警戒 / 中性 | 判灯逻辑 |
| 用途 | 展示 / 诊断 / 预警 / 引导 / 复盘 | 出没在哪个模块 |
| 来源 | 账本事实 / 本金·关系对象 / 参考区设定 / 派生 / 外部行情(预留) | 可信度与更新时机 |
| 信赖度 | 实测 / 含沿用值 / 未校验 / 率不可得 | 承接 `meta.degradations`，判灯闸门 |

纪律：主挂点唯一；多标签但枚举受控；标签只影响「怎么用」，从不改值。（「先行/滞后」轴在当前数据域意义有限，不单列。）

## 4. 分级（判据带 → 灯）

**四态**：🟢 在带内 / 🟡 近边界或轻偏离 / 🔴 超阈 / **⚪ 不可判**（数据不足或口径降级）。⚪ 是宁缺勿滥的落点：**口径降级的指标永远不给绿**。

**带型**：

| 带型 | 例子 | 说明 |
|---|---|---|
| 单向带 | 负债占比、集中度（越低越好）；覆盖度、升值率对照（越高越好） | 简单比较 |
| **适宜带** | 流动性分层占比 | 太少＝风险、太多＝闲置，中间为绿 |
| **双阈值触发带** | 配置偏离 | 绝对 pp 或相对 % 取先触发（R-21；业界「5/25」式） |
| 状态型 | 再平衡状态机 | 静默 / 近阈值 / 已触发 / 回调中 |

**判据来源分级（谁能定阈值）**：① 目标版本（达成度族）；② 配置框架参数——Vanguard 三元组（frequency＋双阈值＋destination，挂框架实例，已冻结）；③ 人设预警规则（`alert_rules` 升级）；④ 代码兜底默认（写明出处）。系统只提案（R-30 反哺），定阈值永远是人（不变量 6）。

**版本化与定格**：阈值随目标版本/框架切换产生新版本；**日常看板用当期尺，复盘按当时生效判据定格**（沿系统架构拍板 6「历史按当时口径定格」同逻辑）；响应注明 `band_basis: current | as-of`。

**口径闸门**：判灯前先过 meta——含沿用值/率不可得/本金未设 → ⚪ 或降档＋注记；复用现有降级键（`NO_DATA` / `DATA_MISSING_CARRY_FORWARD` / `RATE_UNAVAILABLE` / `PRINCIPAL_NOT_SET` / `TWR_LARGE_FLOW_APPROX`）。

**汇合**：单灯 → 子域灯（B4 汇总）→ 全局。规则：红优先于黄；同域双红触发「综合诊断」（指出哪条公式链/哪个切片掉的灯）；**底线类判据（负债、流动性、集中度）不因版本迁移放宽**。

## 5. 分区（版本适配器）

**定义**：分区不是人群分类，而是**判据带与「当期生效上下文」的绑定**；分区变化 → 判据重算，历史节点定格不改写。

| 轴 | 内容 | 支点 |
|---|---|---|
| ① 目标版本 | 偏离永远对「当期目标」 | R-20；三期 C1 |
| ② 配置框架实例＋glide 相位 | 目标占比 w(t) 分段线性；切换留史 | 业务架构拍板 3；R-20 |
| ③ 风险偏好档 | 目标＋风险偏好 → 建议配置 | R-19 |
| ④ 成员/家庭池 | 归属切片与成员级判据 | D（设计即纳入，完整化四期） |

落地形态：**（GoalVersion, FrameworkInstance, RiskProfile, MemberContext）→ 判据带** 的解析函数＋阈值迁移表；不建新实体。

**成员维度（家庭部分并入本设计）**：

- **归属**＝资产项级单值属性：{成员…, 家庭池}；共有一律家庭池，不做多成员共挂/比例（业务架构拍板 6）。
- **分条准则**：分不分条看「**凭证与本金能否独立追溯**」（业务架构拍板 7 同源逻辑）；成员不进资产项身份、不进账户属性名、不拆账本。
- **录入预填**：按同账户既有项的归属规律预填（R-5「最近值预填」惯例），可见可改。
- **收口**：现状归属挂在记录级（无变更史）；随三期-1 收口为资产项级「共有归属」（当前值＋变更留史）；此前同一资产项归属保持一致。
- **视图**：成员级/家庭级两级切片；视图仍仅本人可见，成员报表线下共享（业务架构拍板 6）。
- **家庭池生命周期**（设立/解散/成员进出）仍随 D 期补（系统架构对业务架构的反馈 #6）。
- **多家庭容器**：非目标修订候选，不启动；将来若启动，第一候选形态「一家一库＋只读汇总」（§9-D1）。

## 6. 纵横

**纵向公式链**（能「算回去」的硬链；一条主链）：

1. **净值链**（已上线）：Δ净值＝外部净投入＋内部转移净额＋内生变动 → 可下钻到项/段；
2. **收益链**：升值＝市值 − 本金；TWR/XIRR ← 口径现金流＋估值序列；
3. **三期目标链**：缺口＝目标 − 净值 → 所需年化＝f(缺口, 余期)；偏离＝实际权重 − 当期目标权重 → 双阈值触发。

**横向切片**：属性维度（标的类型/账户/流动性/所有者/（预留）`instrument` 标的面）、账期、资产·负债侧、成员。

**纪律**：纵向只挂一条主链；横向可多切片；算不回去但能解释的（归因、复盘四分类 R-29）放「诊断链」，不进公式链。

## 7. 工程落位

**原则：定义在码、判据在库、值在读。**

- **定义在码**：指标注册表＝`valuation` / `planning` 领域层纯函数；每条＝{id、显示名、子域、标签集、公式引用、输入事实、单位精度、方向、默认带＋出处、判据来源、分区绑定、as-of 语义、下钻引用}。代码是实现真源（不变量 5：LLM 不做算术），测试锁行为；经只读端点暴露给前端通用渲染。**不建「指标表」**。
- **判据在库**：阈值＝参考区数据（现有 `alert_rules` / `allocation_targets.alert_threshold` 升级：版本列＋变更留史＋审计）；框架参数挂配置框架实例。默认带在码内注明出处。
- **值在读**：读时计算（系统架构拍板 10），不物化；响应必带 meta（已有 `build_meta`）→ 扩 `grade` 块 `{state, band_basis, gates[], drill_ref}`。

| 模块 | 职责 |
|---|---|
| `valuation` | 指标函数＋灯引擎骨架＋B4 域级汇总 |
| `planning` | 目标版本、偏离双阈值、分区解析 |
| `advisor` | 只读指标「信息集」冻结快照（R-26） |
| `evidence` | 审计覆盖目标/阈值/归属变更（不变量 8） |

**API（形状示意，契约以 spec 冻结为准）**：`GET /api/metrics`（字典）＋ `GET /api/metrics/status?as_of=…`（值＋灯＋meta＋drill）；复用现有信封/幂等/错误码家法，不新造平行体系。

**前端**：概览＝北极星＋域灯条；分析页＝指标卡（值＋灯＋口径注记＋下钻，复用现有图表）；目标/复盘页随三期新建；`PartialAnnotation` 口径徽标抽成通用组件（MetaBadge）。
