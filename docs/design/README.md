## 设计原则

1. **设计优先、实现可弃**：设计决策不受现状代码约束；现状代码只在①设计冻结后的「保留 vs 重写」实施策略裁决、②用户主动要求参照时出现。
2. **一切可回溯**：所有设计元素可回溯到使命与《设计最高准则》（SDP-1~4，见 `business-architecture.md`）。
3. **单上下文布局**：术语以根目录 `CONTEXT.md` 为准；架构决策以 `docs/adr/` 为准（模型变更走 ADR）。
